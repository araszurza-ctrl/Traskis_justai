# 🍗 Traškis Justiniškių - Pelno ir Kontrolės Sistema

Profesionali Android programėlė traškio biznio valdymui su ataskaitomis, grafikai ir statistika.

## ✨ Pagrindinės Funkcijos

- 📊 **Realaus Laiko Ataskaitai** - Dienos/Savaitės/Mėnesio pelno ir pajamų analizė
- 💰 **Automatinis Skaičiavimas** - Pelnas = Pajamos - Savikaina
- 📦 **Prekių Valdymas** - Suvedi kiekius, matai likučius
- 📈 **Grafikai ir Statistika** - Vizualios diagrams ir analizės
- 📄 **PDF Eksportas** - Eksportuoj ataskaitas į PDF
- 💾 **Offline Veikimas** - Viskas saugoma telefone, internetas nebūtinas
- ⚡ **Paprasta Sąsaja** - Intuityvus dizainas, greitas naudojimas

## 📱 Sistemos Reikalavimai

- Android 8.0 ir naujesnis
- Minimum 50MB laisvos vietos
- Interneto ryšys (nebūtinas dirbti offline)

## 🚀 Diegimas

1. Atsisidegsi APK failą
2. Įdiegsi programėlę
3. Atdarai ir pradedi naudoti!
